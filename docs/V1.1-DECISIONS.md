# V1.1 — décisions

- Multi-propriétaires : deux identifiants GitHub en lecture seule, sélectionnés par propriétaire via une allow-list ; échec fermé si aucun accès. Ne pas utiliser un PAT couvrant tous les dépôts.
- Mobile : publier les prompts dans le résumé privé de la tâche GitHub Actions (`GITHUB_STEP_SUMMARY`) en plus des artefacts de 7 jours, avec limite de taille et présentation résistante aux métadonnées non fiables.
- Pas de schedule, de lecture automatique du quota ni de démarrage Codex Cloud non vérifié.
- Pas de nouvelles dépendances ou permissions en écriture sur les dépôts surveillés.
- Les notifications ntfy doivent rester génériques ; le lien pointe vers l'exécution privée.
